This patch is intended to supply multiplayer cooperative play support for the
multiplayer system, as well as to fix several bugs in the single player game.
The following issues in the single player game have been addressed in these
patches.  Please see the mpcmd.txt for the changes to the multiplayer scripting
engine to support cooperative multiplayer.

Changes for Revenant 1.22
-----------------------------------------

o Fixed incompatible scripting bug with "Sabu" in dungeon.  

o Fixed a save game bug which would cause items to disappear on map.


Changes for Revenant 1.21
-----------------------------------------

o Fixed save game system to address problems with map differencing saves.

o Fixed problem with non working game scripts in single player thieves tower.
  Caused by incompatibility with 1.2 coop scripting system.

Changes for Revenant 1.2
-----------------------------------------

o Revised scripting system which supports multiplayer Coop gameplay.  See
  mpcmd.txt for details.

o Updated graphics engine for compatibility with DX7 based video cards.

o Better CD identification system to identify video CD's so that in
  game video's will play more reliably.

o Faster map loading.

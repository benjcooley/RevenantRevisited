# Format: BARE_TOKEN|RENAMED_TOKEN  — one per line, # comments ignored.
# World data class identifications: TSector + TArea + TAreaManager.
# Anchors used: "%d_%d_%d.DAT" sector-filename literal, "MAP " FCC immediate
# (0x20 << 24 | 'P' << 16 | 'A' << 8 | 'M' = 0x2050414d), area.def parser
# strings, AMBLIGHT/AMBCOLOR/SCRIPT tag literals, callers from already-named
# TMapPane methods (TMapPane::AddObject 0x451090, RemoveObject 0x451610,
# SetPos at 0x459f50, ObjectFlagsChanged 0x451a50).
#
# Field offsets (TSector, retail size = 0x15c):
#   +0x00  walkmap              uint16_t* (10-bit packed: 0..0x3ff = height,
#                               upper bits = retail-only flag bits)
#   +0x04  level                int32
#   +0x08  sectorx              int32
#   +0x0c  sectory              int32
#   +0x14  filename[80]
#   +0x94  usecount             int32 (renamed from `usecount`)
#   +0x98  preloaded?           bool/int (gates Init-lights pass)
#   +0xac  flag (init done?)    int (set by InitLights)
#   +0xb0  preload-state        int (0/1/2 used by LoadSector)
#   +0xb4  statehash            int32 (v14+; computed/stored)
#   +0xb8  numobjects           int32
#   +0xc8  objects[]            ptr-array (TObjectArray, +0xc4 cap, +0xc8 base)
#   +0xcc  objsets[0..5]        SObjSet @ 0x18 stride (six sets:
#                               MOVING/CHARACTER/LIGHTS/PULSE/ANIMATE/NOTIFY).
#                               Source has 7 sets; retail dropped OBJSET_ALL
#                               and stores only sets 1..6 inline.
# Field offsets (TArea, retail size = 0x260):
#   +0x00  name[80]
#   +0x40  level
#   +0x44  flags  (bit 0x2=PLAYERIN, 0x4=SETAMBIENT, 0x8=DONIGHT,
#                  0x10=LOADSCRIPTS, 0x20=PLAYCDMUSIC, 0x40=PLAYAMBIENT,
#                  retail-extra: 0x80, 0x100, 0x200, 0x400, 0x800, 0x1000,
#                  0x2000, 0x4000, 0x8000, 0x10000, 0x20000, 0x40000)
#   +0x48  rects.numitems (short)
#   +0x4a  rects.cap (short)
#   +0x4c  rects.base (SRect[])
#   +0x50  scriptfile[]
#   +0xd0  amblight, +0xd4 nightamblight
#   +0xd8  ambcolor (RGBA bytes), +0xdc nightambcolor
#   +0xe0  lastdaylight (per-area)
#   +0x138 (start of audio-environment data — retail TArea extension)
#   +0x1b8 cdplaynum, +0x1bc cdplaylistsize, +0x1c0 cdplaylist[32]
#   +0x240 cdplayisrandom, +0x244 cdplaypause
#   +0x248 cdplaystart (DWORD tickcount), +0x250 cdplaywait, +0x254 cdplaylength
#   +0x25c TScript* (?) — used as runtime script tracking for the area

# 0x518750: TPlayer::ClearPlayer — THE player-init. 844-byte body. Called
# from ctor + from PlayerManager::Clear (FUN_0051eda0). Does:
#   1. Clears mbrs 0xde, 0xe6/0xe7, 0x199 (=-1), bitfield ranges 0x124..18,
#      0x15c..38, 0xa8..0xb (= 11 equipment slots = NUM_EQ_SLOTS), header
#      stats, 0xb3..7 (= quickspells+misc), 0xbb/0xbc (talisman counts).
#   2. Reads chardata->classdata->statreqs[6] at offset
#      this->chardata(+0x3f*4=+0xfc) ->classdata(+0x190=+400) ->+0x20.
#      Sums absolute values of statreqs[0..5].
#      Computes per-stat-budget = (0x54 - sum) / 6 + 1 = (84-sum)/6+1 in
#      fixed-point .16. statreqs > 0  → that stat is hardcoded to that value;
#      statreqs == 0 → that stat gets one share of the remaining budget.
#      vt[0xe8](slot 58 = SetObjStat) called for stat IDs 0x22..0x27.
#      ⇒ retail stat IDs map: PLRSTAT_FIRST = 0x22 (34); PLRSTAT_STRN..LUCK
#         occupy 0x22..0x27 in source-id order.
#   3. Skill init loop: 11 iterations setting SetObjStat(0x49+i, 0x1e=30).
#      ⇒ SK_FIRST = 0x49 (73); each starting skill = 30.
#   4. Resets talisman list (0xd4) — re-walks chardata's spells (vt[0x12]+0x1c
#      count, FUN_0051ff30 lookup) and rebuilds quickspell-construct entry.
#   5. Calls FUN_0051c660 (~600-byte fn that recomputes stat-derived stats
#      including MaxHealth/MaxFatigue/MaxMana via vt[0x1d8/0x1e0/0x1e8] and
#      sets current values via vt[0x1c4/0x1cc/0x1d4]).
#   6. SetExp(0)/exp-derived stat (uses FUN_0047e920/40 = global counters).
#   7. Clears 60-byte attack-impact log at +0xe8 (10*6 entries).
meth_0x518750|meth_0x518750_TPlayer_ClearPlayer
FUN_00518750|FUN_00518750_TPlayer_ClearPlayer

# Verified mappings (retail SObjectDef-stat-id → source enum):
#   0x22 (34) = PLRSTAT_FIRST + 0  = PLRSTAT_STRN  (Strength)
#   0x23 (35) = PLRSTAT_FIRST + 1  = PLRSTAT_CONS  (Constitution)
#   0x24 (36) = PLRSTAT_FIRST + 2  = PLRSTAT_AGIL  (Agility)
#   0x25 (37) = PLRSTAT_FIRST + 3  = PLRSTAT_RFLX  (Reflexes)
#   0x26 (38) = PLRSTAT_FIRST + 4  = PLRSTAT_MIND  (Mind)
#   0x27 (39) = PLRSTAT_FIRST + 5  = PLRSTAT_LUCK  (Luck)
#   0x49 (73) = SK_FIRST     + 0  = SK_ATTACK
#   ...
#   0x53 (83) = SK_FIRST     + 10 = SK_LOCKPICK
# Implies: CHRFLAGS [0..2], CHRSTATS [3..5] (Health/Fatigue/Mana cur),
#          PLRVALS  [6..7] (Level/Exp), then PLRSTATS  starting at 0x22=34.
# Source enum addition matches — assert: PLRSTAT_FIRST = 8+? (actually
# CHRFLAG_FIRST=0, CHRFLAG=3, CHRSTAT=3, PLRVAL=2 → PLRSTAT_FIRST = 8 in
# source). Retail starts at 0x22=34. Implies 26 type-private CLASS.DEF
# stats live between PLRVAL and PLRSTAT in retail's SObjectDef stat layout
# (chardata-private flags). Treat retail IDs as opaque; use the source enum
# offsets in our port.

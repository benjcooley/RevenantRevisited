## When ground-truth videos arrive

Per effect:

1. **Import**: `tools/refcap/import_clip.py <effect_id> <clip.mp4> --label "<scene>"`
2. **Extract frames** at moments-of-interest (spawn, peak, splat, end): `tools/refcap/extract_frames.py <effect_id> <clip_id> --at NN,NN,NN`
3. **A/B validate**: `tools/vfx/snap_ab.py <effect_id>_BESPOKE <effect_id> --ref <effect_id>` — 3-row grid: reference (top), bespoke, engine
4. **Iterate** until bespoke row matches reference row at every frame
5. **Flip INVENTORY status to `validated`** when A/B passes
6. **Then** consider engine port — A/B against bespoke + reference

## Methodology note (per AGENT_GUIDE §3.2)

  Phase A     Forensics doc
  Phase A.5   Capture original-game reference video  ← USER PROVIDES
  Phase B1    Bespoke port (A/B against reference)
  Phase B2    Engine port (A/B against bespoke + reference)

The bespoke wave covers Phase B1 across the inventory. Phase B2 (engine
wave) is deferred until B1 is done and validated.
